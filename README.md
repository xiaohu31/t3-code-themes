# Lunar Graphite

A dark, graphite themed skin for T3 Code with quiet contrast, cool neutral surfaces, rounded controls, and restrained interaction states.

## Install

1. Open T3 Code theme settings.
2. Import `themes/lunar-graphite.json`.
3. Select **Lunar Graphite**.

The JSON file is the source of truth. It contains the complete color roles and the CSS overrides used by the current published theme.

## Design notes

- Graphite canvas with cool silver text and controls.
- Rounded sidebar rows and search input.
- Composer border and focus treatment without forcing an opaque background, so T3 transparency settings can affect the composer.
- The composer status row is left to T3's native layout.

## Updating

Future themes can be added under `themes/`. Keep each theme in its own JSON file and update the changelog with the T3 theme id and a short list of visual changes.
